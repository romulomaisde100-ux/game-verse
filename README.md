# GameVerse — Projeto acadêmico

Website estático responsivo sobre jogos eletrônicos, desenvolvido com HTML5, CSS3 e Bootstrap 5.3.3.

## Estrutura
- `index.html`: página inicial, apresentação e carrossel de destaques.
- `generos.html`: conteúdo sobre gêneros de jogos e perguntas frequentes.
- `plataformas.html`: conteúdo sobre plataformas e tabela comparativa.
- `style.css`: estilos próprios e regras responsivas.
- `script.js`: pequeno script para atualizar o ano do rodapé.
- `assets/`: ilustrações SVG locais originais.

## Como abrir localmente
1. Extraia a pasta `GameVerse` do arquivo ZIP.
2. Abra `index.html` em um navegador atualizado.
3. Use o menu superior para navegar entre as três páginas.

O Bootstrap é carregado pela CDN jsDelivr. Portanto, a conexão com a internet é necessária para carregar seus estilos, navbar responsiva, carrossel e accordion. As ilustrações estão incluídas localmente.

## Publicação gratuita no GitHub Pages
1. Crie ou entre em uma conta em https://github.com/.
2. Crie um repositório público, por exemplo `gameverse`.
3. Envie todos os arquivos e pastas que estão dentro de `GameVerse` para a raiz do repositório (não envie apenas o ZIP).
4. No repositório, abra **Settings > Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
7. Aguarde a publicação. O GitHub exibirá uma URL semelhante a `https://SEU-USUARIO.github.io/gameverse/`.
8. Abra a URL e teste os três links do menu em computador e celular.

## Antes de entregar
- Substitua `[NOME DO(A) ESTUDANTE]` no arquivo `ENTREGA_SITE.txt`.
- Depois de publicar, substitua `[INSERIR URL PUBLICADA]` pela URL real do GitHub Pages.
- Teste a URL em uma janela anônima e confira as três páginas.

## Tecnologias
HTML5, CSS3, JavaScript básico e Bootstrap 5.3.3. Não utiliza React, Angular, Vue, WordPress ou construtores de sites.
